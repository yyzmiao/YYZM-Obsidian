## 1. Note Template.md（Tasks 日记模板）

包含未完成任务自动汇总、今日新增、每日习惯与日记复盘[span_0](start_span)[span_0](end_span)。

**使用方法：**
1. **安装 Tasks 插件**：进入「设置 -> 第三方插件」，关闭安全模式，搜索 `Tasks` 并安装启用（用于自动汇总任务）[span_1](start_span)[span_1](end_span)。
2. **导入与配置**：将本仓库作为 Vault 打开，或把 `Templates/` 复制到现有库[span_2](start_span)[span_2](end_span)；在「设置 -> 核心插件 -> 模板」中将模板文件夹设为 `Templates`[span_3](start_span)[span_3](end_span)。
3. **调用使用**：新建日记后，点击左侧「插入模板」，选择 `Note Template` 即可[span_4](start_span)[span_4](end_span)。
